Self-hosted so the game never contacts a font CDN at runtime (`src/ui/styles.css`).

| Local file | Family | Source | Licence |
|---|---|---|---|
| cinzel-latin-wght.woff2 | Cinzel (variable weight, Latin subset) | Fontsource `cinzel:vf@latest/latin-wght-normal.woff2` (from Google Fonts `ofl/cinzel`) | [OFL-Cinzel.txt](OFL-Cinzel.txt) |
| cormorant-garamond-latin-wght.woff2 | Cormorant Garamond (variable weight, Latin subset) | Fontsource `cormorant-garamond:vf@latest/latin-wght-normal.woff2` (from Google Fonts `ofl/cormorantgaramond`) | [OFL-CormorantGaramond.txt](OFL-CormorantGaramond.txt) |

Fonts were downloaded from `https://cdn.jsdelivr.net/fontsource/fonts/…` into a new empty
temporary directory and checked as WOFF2 (`wOF2` signature) before copying; the licence texts
come from `https://raw.githubusercontent.com/google/fonts/main/ofl/{cinzel,cormorantgaramond}/OFL.txt`.
The files are unmodified; the Reserved Font Names are not used for any derivative.
