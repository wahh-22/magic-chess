# Key art

Stills of the ARCANA pieces rendered with the game's engine for the title menu and the match
loading screen. Generated by `scripts/art/render-key-art.mjs` — do not edit by hand; how to
re-render, compositions and budget: `docs/art.md`.

| File | Used by |
|------|---------|
| `title.webp`, `title-portrait.webp` | Title menu background (landscape / narrow screens), `src/ui/TitleScreen.tsx`; preloaded by `index.html` |
| `loading-1.webp`, `loading-2.webp` | Match loading screen, alternating between matches (`src/ui/loadingTips.ts`) |
| `*-lqip.webp`, `key-art.json` | Blurred placeholders; their `data:` URIs are inlined in `index.html` and `src/ui/keyArtSources.ts` (a unit test keeps them equal) |

The title art keeps its left 40 % dark for the menu (portrait: the bottom 40 %); the menu
places it with `object-position`. A missing image falls back to the dark gradient.
